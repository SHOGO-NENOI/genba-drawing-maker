# 現場図面メーカー

航空写真や現場写真に施工範囲・寸法・注記を書き込み、面積付きの図面を作成するオフライン対応Webアプリです。

公開版: https://shogo-nenoi.github.io/genba-drawing-maker/

## 現在の実装範囲

Phase 1（プロジェクト基盤）を実装済みです。

- Vite + React + TypeScript の開発基盤
- 日本語UIとレスポンシブレイアウト
- 現場一覧、新規現場作成、図面編集の画面遷移
- PWAマニフェストとオフライン用Service Worker
- 図面・寸法・縮尺・注記・バックアップの共通データ型
- 新規現場入力のバリデーションと単体テスト

編集画面のキャンバス描画、IndexedDB保存、PDF/PNG出力は後続フェーズで実装します。

## 開発

```bash
npm install
npm run dev
```

確認コマンド：

```bash
npm run typecheck
npm test
npm run build
```

## Phase 1 の設計判断

- 保存前の新規現場は `draft` ルートへ遷移し、永続IDの発行はIndexedDBを導入するPhase 4で行います。
- 画像・図形座標は、後続フェーズで元画像ピクセル座標系のまま保存します。
- 実測面積は再計算できるよう、結果値ではなく長方形・三角形・台形の入力寸法を判別可能なUnion型で保持します。
- PWAは自動更新方式です。初回読み込み後、ビルド成果物をHTTPSまたはlocalhostで配信するとオフラインキャッシュが有効になります。
- GitHub Pagesのサブパス配信と再読み込み時の404を避けるため、画面遷移にはHash Routerを使用します。
- フォントは表示品質向上のためGoogle Fontsを指定していますが、通信できない場合は端末の日本語フォントへフォールバックします。アプリ機能自体はネットワークに依存しません。
