# 現場図面メーカー

造園・土木・外構工事の現場写真に施工範囲、寸法、面積、注記を記入し、見積もり添付用の図面を作成するPWAです。

## 現在の実装範囲（Phase 1）

- Vite + React + TypeScript の基盤
- 現場一覧、新規現場作成、図面編集の画面遷移
- PC・スマートフォン対応の日本語UI
- インストール／オフライン起動に向けたPWA設定
- 再編集可能な図面データの共通TypeScript型
- Vitestによる画面スモークテスト

図面編集画面はPhase 2機能を受け入れるためのレイアウトとプレースホルダーです。現場データの永続化、実際のキャンバス編集、面積計算、出力は後続フェーズで実装します。

## 開発コマンド

```bash
npm install
npm run dev
npm run typecheck
npm test
npm run build
```

## Phase 1で採用した初期値

- 画面遷移はReact Routerを使用します。
- PWAは自動更新方式とし、アプリ本体をプリキャッシュします。
- 画像形式はJPEG・PNG・WebPに限定します。
- 座標は元画像ピクセル座標で保持する型設計です。
- 実測面積は結果値だけでなく図形種別と入力寸法を保存します。
- PWAアイコンはPhase 1用のSVGです。ストア配布やOS互換性確認時にPNGアイコンを追加します。

## 次のフェーズ

Phase 2ではKonvaキャンバス、画像読み込み・向き正規化、ズーム／パン、多角形描画・頂点編集、寸法線、注記、Undo／Redoを実装します。
